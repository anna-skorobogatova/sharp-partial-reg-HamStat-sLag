# Validation method

This document states the proof obligations implemented by `validator_core.py`.
The coordinates are

\[
  x=1-s,
  \qquad f_x=-y,
  \qquad x y_x=G(x,f,y),
\]

where

\[
G(x,f,y)=\frac{N(1-x,f,y)-9(1-x)yD(1-x,f,y)}
               {9(2-x)D(1-x,f,y)}.
\]

For `x>0`, the regular right-hand side is

\[
Q(x,f,y)=G(x,f,y)/x.
\]

The real polynomials `D` and `N` are written explicitly in the source. All
input decimals and all stored polynomial centers are exact rational numbers.
Only outward-rounded Arb balls are used for inequalities.

## 1. Singular endpoint, `0 <= x <= h0`

Let `P(x), Y(x)` be the rational Taylor polynomials generated by the code, with
`P'=-Y`, and define the residual

\[
  R(x)=xY'(x)-G(x,P(x),Y(x)).
\]

For a fixed endpoint parameter `A`, write

\[
  f=P+u,\qquad y=Y+v,\qquad a=A-A_c,
\]

and set

\[
  u(x)=a-\int_0^x v(t)\,dt.
\]

Adding `v` to both sides of the correction equation gives the integral map

\[
 v(x)=\frac1x\int_0^x
 \bigl(G(t,P+u,Y+v)-G(t,P,Y)+v-R(t)\bigr)\,dt,
\]

with its continuous limiting value at `x=0`. On a trial tube, the code proves

\[
 |G_f|\le M_f,
 \qquad |G_y+1|\le M_y,
 \qquad q=h_0M_f+M_y<1,
 \qquad |R|\le R_s.
\]

If `A` ranges over a radius `A_r`, the map is a contraction of the closed ball
`||v||_infinity <= V`, where

\[
  V=\frac{M_f A_r+R_s}{1-q}.
\]

Consequently,

\[
 |y-Y|\le V,
 \qquad |f-P|\le A_r+h_0V.
\]

The code separately checks that the explicit endpoint slope interval `B(A)` is
inside the resulting `y(0)` box. Because `|G_y+1|<1`, one has `G_y<0` on the
box, so the endpoint root is unique and is the desired `B(A)` branch. The code
also proves `D>0` on the entire singular tube.

The residual is evaluated without interval cancellation as

\[
 R=\frac{xY'\,[9(2-x)D]-[N-9(1-x)YD]}{9(2-x)D}.
\]

The numerator is an Arb polynomial and is bounded coefficientwise on every
subinterval; the denominator is bounded strictly away from zero.

## 2. Regular continuation

For one regular step `[x0,x0+h]`, put

\[
 z=(f,y),\qquad F(x,z)=(-y,Q(x,f,y)).
\]

The code constructs a rational Taylor polynomial `p` centered at an exact
rational approximation of the incoming ball. Let

\[
 E_0\ge \|z(x_0)-p(0)\|_\infty,
 \qquad
 \rho\ge\|p'-F(x,p)\|_\infty.
\]

On a trial tube of radius `R`, subdivided interval evaluation proves

\[
 L\ge \|D_zF\|_\infty
 \quad\hbox{and}\quad D>0.
\]

Gronwall's inequality gives the deliberately conservative bound

\[
 \|z(x_0+t)-p(t)\|_\infty
 \le e^{Lt}(E_0+\rho t)
 \le \beta:=e^{Lh}(E_0+\rho h).
\]

A step is accepted only when `beta<R`. A first-exit argument then proves that
the solution never leaves the tube on that step. The outgoing ball is
`p(h)+[-beta,beta]^2`.

As in the local proof, the nonzero residual component is bounded through its
polynomial numerator:

\[
 p_y'\,[9x(2-x)D]-[N-9(1-x)p_yD].
\]

## 3. Uniform parameter tube

The endpoint runs use the two exact decimals `A_minus` and `A_plus`
individually. A third run starts from the interval `[A_minus,A_plus]`. The
local contraction includes the full endpoint-parameter radius, and every
regular step propagates the resulting state ball. Therefore its `D` bounds
hold simultaneously for every parameter in that interval, not merely at a
sampled parameter.

## 4. Arithmetic and serialization

- Arithmetic: Arb midpoint-radius balls with rigorous outward rounding.
- Python binding: `python-flint 0.9.0`.
- Bundled FLINT: `3.6.0`.
- Working precision: `512` bits.
- Exact data type for decimals and polynomial centers: FLINT `fmpq`.
- A serialized ball is encoded as

  `([mid_integer - radius_integer], [mid_integer + radius_integer]) * 10^exponent10`,

  with the two exact rational endpoints also stored explicitly.

`verify_certificate.py` checks the exact serialization and all archived strict
inequalities. With `--recompute`, it rebuilds all Taylor polynomials and Arb
bounds from the equations and checks containment in the archive.
